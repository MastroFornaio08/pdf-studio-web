IL TUO ACCOUNT

Collega GitHub

Autorizza il tuo repository con un token personale. Non incollarlo nella chat.

Come creo il token?
  1. Apri GitHub → Fine-grained tokens ↗.
  2. Scegli una scadenza breve e Only select repositories → pdf-actions.
  3. In Repository permissions imposta Contents: Read and write e Actions: Read and write.
  4. Genera il token e incollalo qui. Non occorrono permessi Workflows o accesso a tutti i repository.

Il token viene inviato solo alle API di GitHub. Non viene salvato in cookie, file o archiviazione del browser; ricaricando la pagina dovrai reinserirlo. I documenti caricati restano nella cronologia del repository.
